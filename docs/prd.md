# 一、产品需求文档 (PRD)

> 文档版本: V2（个人版整理）
> 性质：**个人自用工具，不上架 App Store、不对外发布**，无审核、无商业合规负担。

## 1. 项目定位

### 1.1 一句话定位
RidgeLine（山脊线）—— iPhone 上的户外徒步/自驾高精实时海拔导航工具。

### 1.2 核心痛点
传统地图在山区无信号时无法查看海拔/剩余爬升；普通海拔软件缺乏路线导航与高程剖面预览。

### 1.3 个人使用的简化原则
| 事项 | 商业产品要求 | 本产品做法 |
|---|---|---|
| 发布 | App Store 审核、签名、商店素材 | 个人签名/自签，直接安装 |
| 多语言 | 中英等多语言 | 仅中文 |
| UI 打磨 | 新手引导、空态、说明文案 | UI 从简，以数据准确和操作效率优先 |
| 用户体系 | 登录、云同步 | 不需要，单机使用 |
| 稳定性 | 崩溃上报、灰度 | 不需要，坏了直接改代码 |

## 2. 核心场景（按真实使用频率）

| 场景 | 描述 | 关键需求 |
|---|---|---|
| 离线山区徒步 | 无信号，随时查询当前位置海拔、剩余爬升 | 本地 DEM、3D 导航、剖面图 |
| 高原自驾 | 长途驾驶关注垭口/目的地海拔与总爬升 | 目的地海拔预判、全程剖面 |
| 日常快速查询 | 随手查某坐标海拔 | 离线 DEM 检索 |

## 3. 功能需求（按优先级）

### 3.1 导航与地图
| 优先级 | 功能 | 需求描述 |
|---|---|---|
| P0 | 3D 沉浸导航 | 基于 Apple MapKit 路径规划，以 3D 地形样式显示地图与路线 |
| P0 | 路线海拔剖面 | 获取整条路线高程数据，Swift Charts 绘制全程海拔起伏折线图 |
| P0 | 目的地海拔预判 | 导航前/导航中实时展示目的地绝对海拔及预计净爬升 (+m) |
| P1 | 交互式游标 | 剖面图上滑动手指，地图 3D 锚点同步移动，显示对应位置海拔/坡度 |

### 3.2 离线高程引擎
| 优先级 | 功能 | 需求描述 |
|---|---|---|
| P0 | 本地 DEM 检索 | 内置 SRTM1 (.hgt) 高程数据，完全无信号时毫秒级检索海拔 |
| P0 | 按需打包 | 仅内置个人常去区域，控制 App 体积 |
| P1 | 区域扩充 | 支持通过文件 App 导入 .hgt 包，按需扩展覆盖范围 |

> **体积约束（重要）**：单个 .hgt 文件覆盖 1°×1°，大小约 25.9 MB；全中国约 55 GB，不可行。需按个人常去区域选择文件清单（待确认，见 §7）。

### 3.3 传感器融合
| 优先级 | 功能 | 需求描述 |
|---|---|---|
| P0 | 双模高程计算 | GPS（绝对海拔）+ CMAltimeter 气压计（实时相对升降），动态计算垂直速度 (m/min) 和坡度 (%) |
| P2 | 海拔平滑 | 滤波消除 GPS 抖动，保证显示海拔稳定可用 |

### 3.4 平台范围
- 当前版本仅支持 iPhone，不提供 macOS、visionOS 或 watchOS 客户端。

## 4. 工作流定义

### 4.1 导航前
输入起点/终点（支持选点/当前定位） → MapKit 路径规划 → 批量采样提取高程 → 展示全程剖面 + 目的地海拔/净爬升预判。

### 4.2 导航中
实时显示：当前位置、海拔、剩余里程、剩余爬升（+m）；无信号时自动切换本地 DEM，导航不中断。

## 5. 非目标（明确不做）
- App Store 上架、审核材料、发布流程
- 多语言、主题设置、账号体系
- 云同步、社交分享、路线社区
- 非高程类地形数据（坡度矢量图层、岩性图层等）

## 6. 技术约束摘要
- SwiftUI + Swift Concurrency (async/await)，仅 iPhone / iOS 26.5+
- 依赖：Apple MapKit、Swift Charts、CoreMotion
- 离线数据：SRTM1 .hgt 二进制，内置资源或文件导入
- 权限：定位（前台+后台）、运动传感器；UIBackgroundModes: location
